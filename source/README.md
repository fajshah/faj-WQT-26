# WTQ 2026 - The Utility Bill Decoder

## Setup & Execution
1. Install requirements:
   pip install -r requirements.txt
2. Run pipeline:
   python main.py

## AI Usage Declaration
- Model: Gemini 3.1 Flash-Lite (gemini-3.1-flash-lite)
- Tools: Google GenAI SDK, Pandas, Pydantic
- No prebuilt invoice extraction services used.
